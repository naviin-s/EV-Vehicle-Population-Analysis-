# Electric Vehicle Population Analysis Dashboard

## 📊 Project Overview

The **Electric Vehicle Population Analysis Dashboard** is an interactive Microsoft Excel data analytics project developed to analyze electric vehicle adoption and distribution using a large-scale EV population dataset.

The project focuses on transforming raw EV data into meaningful business insights through **data cleaning, transformation, Pivot Table analysis, calculated fields, Pivot Charts, KPIs, slicers, and interactive dashboards**.

The dashboard provides a comprehensive view of EV adoption trends across manufacturers, models, vehicle types, geographic locations, electric range, and Clean Alternative Fuel Vehicle (CAFV) eligibility.

---

## 🎯 Project Objectives

- Analyze the overall electric vehicle population.
- Identify leading EV manufacturers and popular models.
- Compare Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).
- Analyze EV adoption trends across model years.
- Identify geographic areas with higher EV concentrations.
- Analyze electric range across different EV types and manufacturers.
- Evaluate CAFV eligibility distribution.
- Create interactive dashboards for easy exploration and comparison.

## 🔄 Project Workflow

### 1. Data Preparation

Imported the raw EV dataset into Microsoft Excel and used Power Query to prepare the data for analysis.

### 2. Data Cleaning

- Handled missing values.
- Removed duplicate records.
- Standardized column names and data formats.
- Corrected data inconsistencies.
- Prepared fields for analysis and visualization.
- Validated numerical and categorical data.

### 3. Data Analysis

Created Pivot Tables and calculated fields to analyze:

- Total EV population
- EV manufacturers
- EV models
- Model year trends
- BEV vs PHEV distribution
- Average electric range
- Geographic distribution
- CAFV eligibility
- Electric utility distribution

### 4. Dashboard Development

Developed four interactive Excel dashboards using KPI cards, Pivot Charts, slicers, and supporting visualizations.
